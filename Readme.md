# Smart Duka🛒
This is the first offline shop management app for small retail shops in Kenya.

Built with HTML, CSS, Vanilla JavaScript, IndexedDB and Service Workers.
Zero cost. Works without internet.

## Features
- [ ] Products & Stock Management
- [ ] Sales & Revenue Tracking
- [ ] Customer Debts (Deni)
- [ ] Loans Given / Received
- [ ] Expenses Management
- [ ] Daily Closing & Stock Reconciliation
- [ ] Dashboard & Reports
- [ ] Backup & Restore (JSON / CSV)
- [ ] Installable PWA (Works Offline)

## How To Run (For Now)
1. Clone this repo
2. Open folder in VS Code
3. Right-click `index.html` > Open with Live Server

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript
- IndexedDB for offline database
- Service Worker + Manifest for PWA


## Currency
KSh (Kenyan Shillings) by default.
